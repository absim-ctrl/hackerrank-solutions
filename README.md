## 1. Diagonal Difference

### Description

Given a square matrix, calculate the absolute difference between the sums of its two diagonals.

### Concepts Used

* Two-dimensional arrays
* Matrix traversal
* Primary diagonal
* Secondary diagonal
* Absolute difference

### Time Complexity

**O(n²)**

### Space Complexity

**O(n²)**

---

## 2. Dynamic Array

### Description

Implement a dynamic array structure consisting of multiple sequences. Queries are processed using `lastAnswer` and the XOR operation to determine which sequence is accessed.

### Concepts Used

* Dynamic memory allocation
* Arrays
* `malloc()`
* `realloc()`
* `free()`
* XOR operator
* Modular arithmetic

### Time Complexity

The complexity depends on the number of queries and dynamic resizing operations.

### Space Complexity

**O(n + q)**

---

## 5. Sparse Arrays

### Description

For every query string, count how many times that string occurs in the given collection of strings.

### Concepts Used

* Strings
* Character arrays
* `strcmp()`
* Arrays
* Nested loops

### Time Complexity

**O(n × m)** in the general case, where `n` is the number of strings and `m` is the string comparison length.

### Space Complexity

**O(n × m)**
